# Quick Commands

Быстрая командная палитра — открывается по **Ctrl+Shift+P** (настраивается: Settings → Hotkeys).

## Синтаксис

| Ввод | Действие |
|------|----------|
| `:command` | Выполнить команду |
| `:command arg` | Команда с аргументом |
| `:cmd1 \| cmd2` | Цепочка команд (выполняются последовательно) |
| `текст` | Поиск в интернете |
| `:alias add <имя> <команда>` | Создать алиас |

Полный список команд с описаниями — `:help` (страницы: `:help 2`, `:help 3`…).

## Категории команд

### Навигация (nav)
| Команда | Описание |
|---------|----------|
| `:open URL` | Открыть URL в текущей вкладке |
| `:search текст` | Поиск в поисковике |
| `:back` | Назад |
| `:forward` | Вперёд |
| `:reload` | Обновить страницу |
| `:stop` | Остановить загрузку |
| `:home` | Домой (стартовая страница) |

### Вкладки (tab)
| Команда | Описание |
|---------|----------|
| `:tab-close` | Закрыть вкладку |
| `:tab-clone` | Дублировать вкладку |
| `:tab-next` / `:tab-prev` | Следующая / предыдущая вкладка |
| `:tab-focus 3` | Перейти к вкладке по номеру |
| `:tab-list` | Список всех вкладок |
| `:tab-pin` | Закрепить/открепить вкладку |
| `:tab-only` | Закрыть все вкладки, кроме текущей |
| `:tab-mute` / `:tab-unmute` | Выключить / включить звук во вкладке |
| `:tab-group имя` / `:tab-ungroup` | Создать группу из вкладки / убрать из группы |
| `:tab-dedup` | Найти и закрыть вкладки-дубликаты |
| `:undo` | Восстановить последнюю закрытую вкладку |
| `:sleep` / `:sleep-others` | Усыпить вкладку / все, кроме активной |
| `:close-timer 15` | Таймер закрытия вкладки (в минутах) |
| `:split` | Разделённый экран |

### Закладки (bm)
| Команда | Описание |
|---------|----------|
| `:bookmark-add` | Добавить текущую страницу в закладки |
| `:bookmark-list` | Открыть закладки |

### История (hist)
| Команда | Описание |
|---------|----------|
| `:history` | Открыть историю |
| `:history-clear` | Очистить историю |

### Настройки (cfg)
| Команда | Описание |
|---------|----------|
| `:settings раздел` | Открыть настройки (`main`, `search-engine`, `proxy`, `security`, `hotkeys`, …) |
| `:set option value` | Установить опцию (`searchengine`, `theme`) |
| `:custom add/remove/list` | Управление кастомными командами |
| `:alias add/remove/list` | Управление алиасами |
| `:bang имя URL` | Bang для поиска по сайту: `:bang yt https://www.youtube.com/results?q=%s` |
| `:theme-editor` | Визуальный редактор тем |
| `:session-guard on/off` | Session Guard (детекция дублей сессий) |

### Страница (link)
| Команда | Описание |
|---------|----------|
| `:zoom 75` | Установить зум (в процентах) |
| `:hint` | Режим подсказок — клик по ссылкам с клавиатуры |
| `:jseval код` | Выполнить JavaScript в активной вкладке |
| `:view-source` | Исходный код страницы |
| `:reader` | Режим чтения |
| `:findall` | Поиск по всем открытым вкладкам |

Прокрутка наверх/вниз — это vim-команды `:vim-top` / `:vim-bottom`; поиск по странице — `Ctrl+F` (не QC-команды).

### Разное (misc)
| Команда | Описание |
|---------|----------|
| `:help` | Список всех команд (`:help 2` — страница 2) |
| `:calc 2+2` | Калькулятор (результат копируется в буфер) |
| `:emoji запрос` | Поиск и вставка emoji |
| `:en текст` / `:ru текст` | Перевести на английский / русский |
| `:vim` | Список vim-команд (и `:vim-on`, `:vim-toggle`, `:vim-hint`, `:vim-mark`, …) |
| `:dark` | Принудительный тёмный режим |
| `:print` | Печать страницы |
| `:fullscreen` | Полноэкранный режим |
| `:download-open` | Открыть последнюю загрузку |
| `:readaloud` | Чтение страницы вслух (TTS) |
| `:sidebar` | Панель закладок |
| `:incognito` | Открыть инкогнито-вкладку |
| `:clear-data` | Полная очистка данных (кэш, cookies, SW, localStorage, IndexedDB) |
| `:profile-switch имя` | Переключить профиль |
| `:autoscroll` / `:equalizer` / `:hover-translate` | Автоскролл / эквалайзер / hover-перевод |
| `:widget` | Мини-режим палитры (виджет) |
| `:zapper` | Скрыть элемент на странице (Element Zapper) |
| `:version` | Информация о версии |
| `:quit` | Выход из браузера |

Скриншоты — не QC-команда: кнопка на панели инструментов или настраиваемый хоткей (Settings → Hotkeys).

## Кастомные команды

Создание через QC:
```
:custom add mycommand https://example.com
:custom add hello js:alert('Привет!')
```

Два типа кастомных команд:
- **URL** — открывает указанный URL
- **JavaScript** — выполняет JS в активной вкладке

## Алиасы

Алиасы позволяют создавать короткие имена для существующих команд:
```
:alias add o open        // :o теперь вызывает :open
:alias add dup tab-clone // :dup теперь дублирует вкладку
:alias remove o          // удалить алиас
:alias list              // список алиасов
```

## Bang-команды

`!`-стиль как в DuckDuckGo — короткие имена для поиска по конкретному сайту:
```
:bang yt https://www.youtube.com/results?q=%s
:yt котики               // поиск на YouTube
:bang list               // список bang-ов
:bang remove yt          // удалить
```

## Предпросмотр

QC показывает живой предпросмотр для:
- Результатов калькулятора (`:calc`)
- URL для открытия (`:open`)
- Уровня зума (`:zoom`)
- Информации о команде
- Кастомных команд

## Unified Command Bar

При включении в **Settings → Customization → Address bar → Unified Command Bar** результаты QC-команд отображаются в выпадающем списке адресной строки вместе с обычными подсказками (закладки, история, поиск).
