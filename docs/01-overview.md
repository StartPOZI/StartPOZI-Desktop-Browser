# Обзор браузера

## Что такое StartPOZI Desktop Browser

StartPOZI — это десктопный браузер на базе Electron (Chromium), ориентированный на приватность, кастомизацию и удобство для опытных пользователей.

## Ключевые особенности

- **Приватность**: встроенный блокировщик рекламы (Cliqz), защита от фингерпринтинга, Tor-поддержка, очистка URL от трекеров
- **Кастомизация**: система тем (.thmz), настраиваемая панель инструментов, vim-управление, пользовательские скрипты
- **Оптимизация**: засыпание вкладок, eco-freeze анимаций, Data Saver, Battery Saver, менеджер задач
- **Продуктивность**: Quick Commands (как в VS Code), многооконный режим, workspaces, мульти-поиск
- **Медиа**: эквалайзер, медиа-контролы, picture-in-picture, reader mode, hover-перевод

## Архитектура

```
StartPOZI Desktop Browser
├── main.js              — главный процесс Electron (~5600 строк)
├── renderer.js          — UI логика браузера (~9700 строк)
├── preload.js           — мост IPC для главного окна
├── preload-webview.js   — инъекция в webview (vim, eco-freeze, security)
├── index.html           — главное окно браузера
├── style.css            — стили браузера
├── Settings.html        — страница настроек (самостоятельное приложение)
├── TaskManager.html     — менеджер задач
├── Library.html         — библиотека (история, закладки, загрузки)
├── i18n.js              — система переводов
├── adblocker.js         — движок блокировки рекламы
├── MainPage/            — встроенная стартовая страница с виджетами
├── ErrorPage/           — страница ошибки (с игрой Breakout!)
├── SecurityTest.html    — страница тестирования безопасности
├── OptimizationTest.html— страница тестирования оптимизации
├── locales/             — файлы переводов (ru.json)
└── docs/                — документация
```

## Технологии

| Компонент | Технология |
|-----------|-----------|
| Движок | Electron 42 + Chromium |
| Блокировщик | @cliqz/adblocker-electron |
| Архивы | adm-zip + archiver |
| Tor | встроенный Tor-binary + мосты |
| Шифрование | локальное шифрование паролей с master password |

## Системные требования

- Windows 10+, macOS 11+, или Linux (Ubuntu 20.04+)
- Минимум 4 ГБ ОЗУ (рекомендуется 8 ГБ)
- 500 МБ свободного места
