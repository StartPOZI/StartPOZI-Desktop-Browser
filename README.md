## О проекте

**StartPOZI** — это современный браузер с акцентом на приватность, анонимность и глобальную защиту данных. Разработанный для пользователей, которые ценят свою цифровую безопасность и свободу в интернете.

### 🔒 Ключевые особенности

- **Приватность и анонимность**: Встроенная защита от трекеров, криптографическая защита данных и режим инкогнито по умолчанию
- **Глобальная защита**: Многоуровневая система безопасности для защиты от угроз любого уровня
- **Поиск StartPOZI**: Встроенный приватный поисковый движок, который не отслеживает ваши запросы
- **Гибкая настройка**: Широкие возможности кастомизации интерфейса и функций под ваши нужды
- **Кроссплатформенность**: Полная поддержка Windows, Linux и macOS

## 🚀 Установка

### Windows
1. Скачайте `StartPOZI-Windows.exe` из папки [Download](Download/)
2. Запустите установочный файл
3. Следуйте инструкциям мастера установки

### Linux
```bash
tar -xzf StartPOZI-Linux.tar.gz
cd StartPOZI
./install.sh
```

### macOS
1. Скачайте `StartPOZI-macOS.dmg`
2. Откройте образ диска
3. Перетащите StartPOZI в папку Applications

## ⚙️ Настройка

StartPOZI предлагает расширенные настройки для максимального контроля:
- Настройки уровня приватности (базовый, повышенный, максимальный)
- Кастомизация интерфейса
- Управление расширениями
- Настройки сети и прокси
- Конфигурация поисковых систем
