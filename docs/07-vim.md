# Vim-управление

Полная эмуляция vim внутри webview. Настраивается в **Settings → Hotkeys → Vim controls**.

## Включение

Включается в настройках или QC-командой `:vim`. Статус-бар отображается в правом нижнем углу.

## Режимы

| Режим | Индикатор | Описание |
|-------|-----------|----------|
| Normal | `NORMAL` | Базовый режим, все команды |
| Insert | `— INSERT —` | Обычный ввод текста (нажать `i`) |
| Visual | `— VISUAL —` | Выделение текста (нажать `v`) |
| Visual Line | `— VISUAL LINE —` | Построчное выделение (нажать `V`) |
| Hint | `HINT` | Переход по ссылкам буквами (нажать `f`) |

## Движение

| Клавиша | Действие |
|---------|----------|
| `h` | Влево |
| `j` | Вниз |
| `k` | Вверх |
| `l` | Вправо |
| `w` | Следующее слово |
| `b` | Предыдущее слово |
| `0` | В начало строки |
| `$` | В конец строки |
| `gg` | В начало страницы |
| `G` | В конец страницы |
| `Ctrl+d` | Пол-экрана вниз |
| `Ctrl+u` | Пол-экрана вверх |
| `Ctrl+f` | Экран вниз |
| `Ctrl+b` | Экран вверх |

## Ссылки (Hint mode)

| Клавиша | Действие |
|---------|----------|
| `f` | Открыть ссылку в текущей вкладке |
| `F` | Открыть ссылку в новой вкладке |

После нажатия `f`/`F` на всех видимых ссылках появляются буквенные подсказки. Введите буквы, чтобы перейти по ссылке.

## Выделение (Visual mode)

| Клавиша | Действие |
|---------|----------|
| `v` | Войти в visual mode |
| `V` | Войти в visual line mode |
| `h/j/k/l` | Расширить выделение |
| `w/b` | Выделить по словам |
| `y` | Копировать выделение (yank) |

## Метки

| Клавиша | Действие |
|---------|----------|
| `m{буква}` | Установить метку |
| `'{буква}` | Перейти к метке |

## Навигация

| Клавиша | Действие |
|---------|----------|
| `:[[` | Предыдущая страница |
| `]]` | Следующая страница |
| `:` | Открыть Quick Commands |
| `/` | Поиск на странице |
| `n` | Следующее совпадение |
| `N` | Предыдущее совпадение |

## Прочее

| Клавиша | Действие |
|---------|----------|
| `i` | Войти в insert mode |
| `Esc` | Выйти в normal mode |
| `r` | Обновить страницу |
| `yy` | Копировать URL страницы |
| `zi` / `zo` | Зум увеличить / уменьшить |
| `zz` | Сбросить зум |
| `gd` | Перейти к определению (ссылка под курсором) |

## Раскладки клавиатуры

Vim-команды работают с **любой раскладкой** (русской, английской и др.) благодаря преобразованию `e.code` в символы QWERTY.
