Tips
.onion not working?
— Open check.torproject.org — it should say "Congratulations".
— If Tor was not running at browser start, restart the browser after enabling the proxy (Chromium needs a DNS flag at startup).
— If Tor is blocked in your region → you need bridges (obfs4/snowflake). Paste them into the "Bridges" field above before starting Tor.
— Find your Tor port: cat /etc/tor/torrc | grep -i socksport (default 9050, or 9150 for Tor Browser).
— Security hardening (disable JS / WebGL / fonts / etc.) has been moved to the "Security" section.

Auto-sleep on low memory
Puts old inactive tabs to sleep when RAM exceeds the threshold. This is a separate feature from timed sleep above — the trigger here is memory, not time. "Disabled" = off.
Open tab limit
When exceeded, the oldest inactive tabs are put to sleep automatically
Clear Service Workers of sleeping tabs
Frees memory: unregisters background Service Workers when a tab is put to sleep (the site will re-register on the next visit)
Real-time optimization (eco-freeze)

Freezes CSS animations and requestAnimationFrame in background tabs — the main cause of lag when many tabs with animations are open (in Firefox this works out of the box). Media (video/audio) keeps playing. Whitelisted "never sleep" tabs are not frozen.

Freeze animations in background tabs
Pauses animations/rAF in all inactive tabs
Auto-freeze heavy tabs by CPU
Freezes a background tab if it uses CPU above the threshold for ~6 sec (works even if the top toggle is off)

Tip: keep the top toggle on for continuous protection, or enable only CPU auto-freeze for targeted intervention. The current state is visible in the Task Manager ("frozen" badge).

Data Saver
Blocks large images and injects lazy-loading to reduce traffic. Media (video/audio) is not affected.
Battery Saver (laptops only)
Automatically enables eco-freeze and disables preloading when battery is below 20% and discharging
Whitelist "never sleep"

Domains in this list are never put to sleep (neither by timer nor on low memory). Matches by domain and subdomains: gmail.com also protects mail.google.com.

"Sleep all except current" in context menu
Adds an item to the right-click tab menu. Frees memory while keeping the active tab and whitelist.
