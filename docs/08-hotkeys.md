# Горячие клавиши

## Основные

| Сочетание | Действие |
|-----------|----------|
| `Ctrl+T` | Новая вкладка |
| `Ctrl+W` | Закрыть вкладку |
| `Ctrl+Shift+T` | Восстановить закрытую вкладку |
| `Ctrl+Tab` | Следующая вкладка |
| `Ctrl+Shift+Tab` | Предыдущая вкладка |
| `Ctrl+L` | Фокус на адресную строку |
| `Ctrl+R` / `F5` | Обновить |
| `Ctrl+Shift+R` | Обновить без кэша |
| `Ctrl+H` | История |
| `Ctrl+J` | Загрузки |
| `Ctrl+D` | Добавить закладку |
| `Ctrl+F` | Найти на странице |
| `Ctrl+P` | Печать |
| `Ctrl+S` | Сохранить страницу |
| `F11` | Полноэкранный режим |
| `F12` | Инструменты разработчика |
| `Escape` | Закрыть панель/overlay |

## Быстрые команды и поиск

| Сочетание | Действие |
|-----------|----------|
| `Ctrl+Shift+P` | Quick Commands |
| `Alt+Enter` | Мульти-поиск (в адресной строке) |

## Навигация

| Сочетание | Действие |
|-----------|----------|
| `Alt+←` | Назад |
| `Alt+→` | Вперёд |
| `Alt+Home` | Домой |

## Вкладки

| Сочетание | Действие |
|-----------|----------|
| `Ctrl+1` ... `Ctrl+8` | Перейти к вкладке 1–8 |
| `Ctrl+9` | Последняя вкладка |
| `Ctrl+Shift+N` | Новая вкладка инкогнито |

## Менеджер задач и инструменты

| Сочетание | Действие |
|-----------|----------|
| `Shift+Esc` | Менеджер задач |

## Окно

| Сочетание | Действие |
|-----------|----------|
| `Ctrl+N` | Новое окно |
| `Ctrl+Shift+Q` | Выход |
| `Ctrl+M` | Свернуть |

## Vim (когда включён)

| Сочетание | Действие |
|-----------|----------|
| `i` | Insert mode |
| `Esc` | Normal mode |
| `v` | Visual mode |
| `f` | Hint mode (ссылки) |
| `/` | Поиск |
| `:` | Quick Commands |

## Настройка

Все горячие клавиши можно переназначить в **Settings → Hotkeys**. Рекордер клавиш записывает нажатие и сохраняет его.
