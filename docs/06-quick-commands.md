# Quick Commands

Быстрая командная палитра — открывается по **Ctrl+Shift+P**.

## Синтаксис

| Ввод | Действие |
|------|----------|
| `:command` | Выполнить команду |
| `:command arg` | Команда с аргументом |
| `:cmd1 \| cmd2` | Цепочка команд (выполняются последовательно) |
| `текст` | Поиск в интернете |
| `:alias name cmd` | Создать алиас |

## Категории команд

### Навигация (nav)
| Команда | Описание |
|---------|----------|
| `:open URL` | Открыть URL |
| `:search текст` | Поиск в поисковике |
| `:back` | Назад |
| `:forward` | Вперёд |
| `:reload` | Обновить |
| `:home` | Домой |

### Вкладки (tab)
| Команда | Описание |
|---------|----------|
| `:tab-new` | Новая вкладка |
| `:tab-close` | Закрыть вкладку |
| `:tab-list` | Список всех вкладок |
| `:tab-pin` | Закрепить вкладку |
| `:tab-duplicate` | Дублировать вкладку |
| `:split` | Разделённый экран |

### Закладки (bm)
| Команда | Описание |
|---------|----------|
| `:bm-add` | Добавить закладку |
| `:bm-list` | Список закладок |

### История (hist)
| Команда | Описание |
|---------|----------|
| `:hist` | История |
| `:hist-clear` | Очистить историю |

### Настройки (cfg)
| Команда | Описание |
|---------|----------|
| `:settings` | Открыть настройки |
| `:custom add/remove/list` | Управление кастомными командами |
| `:alias add/remove/list` | Управление алиасами |

### Страница (link)
| Команда | Описание |
|---------|----------|
| `:zoom 75` | Установить зум |
| `:scroll top` | Прокрутить наверх |
| `:scroll bottom` | Прокрутить вниз |
| `:find текст` | Найти на странице |

### Разное (misc)
| Команда | Описание |
|---------|----------|
| `:help` | Список всех команд |
| `:calc 2+2` | Калькулятор |
| `:emoji запрос` | Поиск emoji |
| `:en текст` | Перевести на английский |
| `:ru текст` | Перевести на русский |
| `:vim` | Список vim-команд |
| `:screenshot` | Скриншот |

## Кастомные команды

Создание через QC:
```
:custom add mycommand
```

Два типа кастомных команд:
- **URL** — открывает указанный URL
- **JavaScript** — выполняет JS в активной вкладке

## Алиасы

Алиасы позволяют создавать короткие имена для существующих команд:
```
:alias add o open      // :o теперь вызывает :open
:alias add t tab-new   // :t теперь вызывает :tab-new
```

## Предпросмотр

QC показывает живой предпросмотр для:
- Результатов калькулятора (`:calc`)
- URL для открытия (`:open`)
- Уровня зума (`:zoom`)
- Информации о команде
- Кастомных команд

## Unified Command Bar

При включении в **Settings → Customization → Address bar → Unified Command Bar** результаты QC-команд отображаются в выпадающем списке адресной строки вместе с обычными подсказками (закладки, история, поиск).
