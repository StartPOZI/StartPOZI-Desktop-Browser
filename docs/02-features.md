# Возможности

## Вкладки и навигация

| Функция | Описание |
|---------|----------|
| Workspaces | Группировка вкладок в именованные пространства с иконками и цветами |
| Засыпание вкладок | Автоматическая заморозка неактивных вкладок (5–60 мин) для экономии ОЗУ |
| Ленивая загрузка | При запуске загружается только активная вкладка |
| Лимит вкладок | Автозасыпание старых вкладок при превышении лимита (10–100) |
| Сон всех вкладок | Контекстное меню: «Усыпить все кроме текущей» |
| Инкогнито | Приватные вкладки с отдельной сессией |
| Разделённый экран | Просмотр двух вкладок бок о бок |
| Поиск по всем вкладкам | Поиск текста внутри всех открытых вкладок |
| Восстановление сессии | Автоматическое reopening вкладок при запуске |
| Превью вкладок | Миниатюра страницы при наведении на вкладку |

## Адресная строка и поиск

| Функция | Описание |
|---------|----------|
| Омнибокс | Единая строка для URL и поисковых запросов |
| Подсказки | Выпадающий список: закладки, история, поисковые подсказки |
| Выбор поисковика | StartPOZI / Google / DuckDuckGo / Bing / свой |
| Мульти-поиск | Поиск сразу в нескольких поисковиках (Alt+Enter) |
| Unified Command Bar | QC-команды в выпадающем списке адресной строки |

## Приватность и блокировка

| Функция | Описание |
|---------|----------|
| Блокировщик рекламы | Движок Cliqz; блокирует рекламу и трекеры; статистика по страницам |
| SponsorBlock | Авто-пропуск спонсорских сегментов YouTube |
| Element Zapper | Интерактивный выбор и скрытие элементов на странице |
| Custom фильтры | Пользовательские правила в формате EasyList |
| Списки фильтров | Подключение внешних списков (EasyList, EasyPrivacy и др.) |
| Custom hide styles | CSS-правила для скрытия элементов по доменам |
| Журнал блокировки | Просмотр всех заблокированных запросов |
| Очистка URL | Удаление utm_*, fbclid, gclid и разворачивание редиректов |
| Sanitize URL | Предупреждение о punycode (фишинг) и учётных данных в URL |
| Break Loupe | Мгновенное удаление всех cookies кроме внутренних страниц |

## Безопасность

| Функция | Описание |
|---------|----------|
| Защита от WebRTC-утечек | Блокировка WebRTC для предотвращения утечки локального IP |
| Защита от фингерпринтинга | Шум canvas, подмена userAgent/platform/hardwareConcurrency |
| Блокировка автоплея | Медиа воспроизводится только по клику |
| Изоляция сайтов | Раздельные cookie/localStorage для каждого домена |
| HTTPS-only | Автоматическое перенаправление HTTP → HTTPS |
| Referrer policy | Отправка только origin, не полного пути |
| Блокировка 3rd-party cookies | Блокировка межсайтовых cookies |
| Блокировка mixed content | Блокировка HTTP-ресурсов на HTTPS-страницах |
| Блокировка уведомлений | Авто-отклонение запросов на уведомления |
| Блокировка геолокации | Запрет доступа к местоположению |
| Блокировка WebGL fingerprint | Подмена информации о GPU |
| Блокировка Clipboard API | Запрет чтения/записи буфера обмена |
| Letterboxing | Округление размеров окна для защиты от fingerprinting |
| Tor hardening (CSP) | Независимые переключатели: JS, WebGL, шрифты, плагины, iframes |

## Tor и прокси

| Функция | Описание |
|---------|----------|
| Поддержка прокси | HTTP/HTTPS/SOCKS4/SOCKS5/Tor |
| Встроенный Tor | Запуск/остановка Tor (SOCKS5 9050) с мостами |

| Tor мосты | Поддержка obfs4 и snowflake |
| Новая личность (NewNym) | Запрос нового Tor-контура |
| Авто-Tor для .onion | Автоматическое включение Tor для .onion-адресов |

## Менеджер паролей

| Функция | Описание |
|---------|----------|
| Шифрованное хранилище | Все пароли хранятся локально, зашифрованные |
| Master password | Установка/проверка/смена мастер-пароля |
| CRUD | Добавление/редактирование/удаление паролей |
| Автозаполнение | Автоматическое заполнение на подходящих сайтах |
| Генератор паролей | Настраиваемая генерация надёжных паролей |
| Проверка утечек | Проверка через Have I Been Pwned |
| TOTP / 2FA | Генерация TOTP-кодов; QR-настройка 2FA |
| Сканер QR | Сканирование QR-кодов со страницы/камеры |
| Импорт | Из Google Auth, TXT-файла, GA-экспорта |
| Экспорт/импорт | Резервное копирование базы паролей |

## Оптимизация

| Функция | Описание |
|---------|----------|
| Лимт дискового кэша | 100/250/500 МБ / безлимит |
| Очистка памяти при сворачивании | Освобождение ОЗУ при минимизации окна |
| GPU-акселерация | Переключение аппаратного ускорения |
| Лимит процессов рендеринга | 1/2/4/безлимит |
| Предзагрузка ссылок | Предзагрузка страниц при наведении |
| Авто-сон при нехватке ОЗУ | Засыпание старых вкладок при превышении порога (512 МБ–4 ГБ) |
| Очистка Service Workers | От unregister SW у спящих вкладок |
| Eco-freeze | Заморозка CSS-анимаций и requestAnimationFrame в фоновых вкладках |
| Авто-заморозка по CPU | Заморозка фоновых вкладок с высоким CPU (~6 сек) |
| Data Saver | Блокировка крупных изображений + lazy-loading |
| Battery Saver | Авто eco-freeze + отключение предзагрузки при заряде < 20% |
| Whitelist «не спать» | Домены, которые никогда не усыпляются |
| Менеджер задач | Память/CPU/статус по каждой вкладке и процессу (Shift+Esc) |
