# Частые вопросы — FAQ (RU)

EN version: `docs/en/13-faq.md`. Быстрая справка также встроена в браузер: `about:help`.

---

## Приватность

**Куда отправляются мои данные?**
История, закладки, пароли, счётчики частых сайтов — только на ваше устройство. Сеть контактируют лишь опциональные сервисы (поисковые подсказки, переводчик, проверка утечек HIBP, диагностика соединения) — каждый отключается в Settings → Security → External services.

**Почему при вводе в строку что-то уходит в интернет?**
Это поисковые подсказки. Отключить: Settings → Security → External services → Search suggestions. Подсказки также выключаются отдельно от частых сайтов/закладок (Settings → Search → Address bar suggestions).

**Что такое 🔥 в подсказках адресной строки?**
«Частые сайты»: домены, открытые 3+ раза за последние 48 часов. Отключение и очистка счётчиков — Settings → Search → Address bar suggestions → Clear remembered frequent sites.

**Tor правда прячет весь трафик?**
Весь браузерный трафик идёт через SOCKS5 Tor (включая DNS через прокси). Проверьте цепочку: about:tor → диагностика exit-IP. Watchdog при падении Tor переключает на прямое соединение — следите за индикатором.

**Как удалить данные одного сайта?**
Замочек в адресной строке → «Удалить cookie и данные сайта». Удаляются cookies (включая доменные), localStorage, IndexedDB, service workers, кэши — только этого домена, в сессии текущей вкладки.

## Работа браузера

**Вход в Google не работает / просит подтверждение?**
На страницах входа браузер представляется Firefox, чтобы Google не запускал Chrome-аттестацию. Если проблема осталась: Site Info → удалить данные сайта → перезагрузить страницу и попробовать снова.

**Как открыть недавно закрытую вкладку?**
`Ctrl+Shift+T` или Quick Commands (`Ctrl+Shift+P`) → `undo`.

**Как найти вкладку среди многих?**
Начните печатать в адресной строке — внизу списка появится секция «Открытые вкладки». Также есть Search tabs (`about:taskmanager` и кнопка на панели).

**Быстрый поиск в конкретном движке?**
Bang-ключевые слова: `g запрос` (Google), `d` (DuckDuckGo), `b` (Bing), `y` (YouTube), `w` (Wikipedia).

**Сайт тормозит. Где найти причину?**
`about:taskmanager` — потребление CPU/памяти по вкладкам. Гибернация вкладок и eco-freeze — в Settings → Optimization.

**Видео/DRM (Netflix) не играет?**
Установите Widevine-рантайм: `npm run drm:setup` (из исходников) или включите DRM в сборке. Стоковый Electron не включает CDM.

## Пароли и бэкапы

**Забыл мастер-пароль хранилища.**
Расшифровать невозможно (AES-256-GCM + scrypt, ключ не хранится). Восстановите из бэкапа `.spzi`, если он делался с паролем.

**Безопасна ли проверка утечек паролей?**
Да: используется k-anonymity HIBP — уходит только первые 5 символов SHA-1 хэша, сам пароль не покидает устройство.

**Чем отличается полный бэкап от бэкапа без секретов?**
Полный `.spzi` содержит пароли и TOTP и шифруется AES-256-GCM (пароль обязателен). Без секретов — история/настройки/заметки без паролей.

## Темы и скрипты

**Как установить тему?**
Settings → Customization → Themes → Import theme → файл `.thmz`. Или создать свою: `about:themeeditor`.

**Может ли тема/скрипт украсть данные?**
Темы: нет — удалённые ресурсы в CSS запрещены. Скрипты `.skit`: права заявляются в манифесте (`storage`/`clipboard`/`notifications`), незаявленные API недоступны, импорт падает на неизвестных правах. Ставьте скрипты только из доверенных источников.

**Скрипт не срабатывает.**
Проверьте: `match` покрывает адрес, скрипт включён в about:scripts, смотрите журнал ошибок там же.

## Обновление

**Как обновиться?**
Settings → About → проверка обновлений (GitHub Releases). Установка поверх сохраняет данные.
