# Оптимизация

Все настройки в **Settings → Optimization**.

## Управление памятью

### Засыпание вкладок
Автоматически замораживает неактивные вкладки (кроме вкладок с видео) через заданное время.

| Опция | Значения |
|-------|----------|
| Таймер | Отключено / 5 / 10 / 15 / 25 / 60 мин |

### Ленивая загрузка вкладок
При запуске загружается только активная вкладка. Остальные загружаются при первом клике.

### Лимит вкладок
При превышении количества вкладок самые старые неактивные автоматически засыпают.

| Опция | Значения |
|-------|----------|
| Лимит | Отключено / 10 / 15 / 20 / 30 / 50 / 100 |

### Авто-сон при нехватке ОЗУ
Старые неактивные вкладки засыпают, когда использование ОЗУ превышает порог.

| Опция | Значения |
|-------|----------|
| Порог | Отключено / 512 МБ / 1 ГБ / 1.5 ГБ / 2 ГБ / 3 ГБ / 4 ГБ |

### Очистка Service Workers
Отменяет регистрацию Service Workers у засыпающих вкладок для освобождения памяти. Сайты перерегистрируются при следующем визите.

### Whitelist «никогда не спать»
Список доменов, которые никогда не усыпляются. Сравнение по домену и поддоменам: `gmail.com` также защищает `mail.google.com`.

## Eco-Freeze

Замораживает CSS-анимации и `requestAnimationFrame` в **фоновых** вкладках — основная причина лагов при большом количестве вкладок с анимациями.

| Опция | Описание |
|-------|----------|
| Freeze animations in background tabs | Заморозка анимаций/rAF во всех неактивных вкладках |
| Auto-freeze heavy tabs by CPU | Заморозка фоновой вкладки, если CPU выше порога ~6 сек |

Порог CPU: 10% / 15% / 25% / 40%

Медиа (видео/аудио) **не затрагивается** — воспроизведение продолжается.

## Data Saver

Блокирует крупные изображения и внедряет lazy-loading для экономии трафика:
- Устанавливает `loading="lazy"` на все `<img>` и `<iframe>`
- Использует IntersectionObserver для отложенной загрузки внеэкранных изображений
- Удаляет `srcset` для предотвращения загрузки hi-res вариантов
- Медиа (видео/аудио) не затрагивается

## Battery Saver (только ноутбуки)

Автоматически включает eco-freeze и отключает предзагрузку, когда:
- Уровень заряда ниже 20%
- Ноутбук работает от батареи (не заряжается)

## Производительность

| Опция | Описание |
|-------|----------|
| Disk cache limit | Лимт дискового кэша (100/250/500 МБ / безлимит) |
| Clear memory on minimize | Освобождение ОЗУ при минимизации окна |
| GPU hardware acceleration | Аппаратное ускорение GPU |
| Render process limit | Лимит процессов рендеринга (1/2/4/безлимит) |
| Link preloading | Предзагрузка страниц при наведении на ссылку |

## Менеджер задач

Откройте через **Shift+Esc** или кнопку в настройках оптимизации.

Показывает для каждой вкладки и процесса:
- Память (ОЗУ)
- CPU (%)
- Статус (active / sleeping / frozen)
- Тип процесса (Main / GPU / Utility / Zygote / Sandbox)

Доступные действия:
- Закрыть вкладку
- Усыпить вкладку
- «Усыпить все кроме активной»
