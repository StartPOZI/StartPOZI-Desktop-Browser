# Руководство по настройкам (RU)

Полный справочник по всем разделам **Settings → `about:settings`**. EN version: `docs/en/11-settings-guide.md`.

**Поиск по настройкам**: поле вверху сайдбара — ищет по всем карточкам на текущем языке, Enter/Clicк переносит к нужной карточке (секция загружается, карточка подсвечивается). Русские запросы находят английские термины («куки» → cookie). Deep-link: `about:settings?q=cookie` (или `#q=`).

---

## Search — Поиск

| Опция | Описание |
|---|---|
| Search engine | Движок по умолчанию: StartPOZI, Google, DuckDuckGo, Bing или свой URL с `?q=` |
| Search type | Что ищется по умолчанию из строки и контекстного меню выделения: Web / Images / Videos / News / Maps |
| Onion search engines | При активном Tor поиск идёт через `.onion`-зеркала (StartPOZI, DuckDuckGo) |
| Multi-search | Поиск сразу в нескольких движках (`Alt+Enter` в адресной строке); список встроенных + свои движки |
| Address bar suggestions | «Frequent sites» — сайты, открытые 3+ раза за 48 часов, предлагаются первыми (🔥); «Bookmarks» — поиск по закладкам в строке. Обе функции отключаются; кнопка **Clear remembered frequent sites** стирает запомненные счётчики |

### Умная адресная строка
- **Bang-поиск**: `g запрос` → Google, `d` → DuckDuckGo, `b` → Bing, `y` → YouTube, `w` → Wikipedia (язык браузера).
- **Открытые вкладки**: внизу списка подсказок — секция «Открытые вкладки» с совпадениями; Enter/клик переключает на вкладку.
- **Команды**: ввод `:` показывает Quick Commands (~60 команд).

## Security — Безопасность (`about:security`)

### Приватность
| Переключатель | Действие |
|---|---|
| URL cleaner | Удаляет трекинг-параметры (`utm_*`, `fbclid`, `gclid`, сотни других) и разворачивает редирект-обёртки |
| Sanitize URL | Предупреждает о punycode-доменах (фишинг) и учётных данных в URL (`user:pass@site`) |
| WebRTC leak protection | Блокирует утечку реального IP через WebRTC (важно при VPN/Tor) |
| Fingerprint protection | Шум в Canvas/AudioContext, подмена платформы/языков/памяти/WebGL |
| Letterboxing | Округляет вьюпорт до 200×100 — сайт не видит реальное разрешение |
| Block autoplay / notifications / geolocation | Медиа и запросы только по клику/запрету |
| HTTPS-only | Автоперенаправление HTTP → HTTPS |
| Referrer policy | Отправляется только origin |
| Block 3rd-party cookies / mixed content | Межсайтовые cookies и HTTP-контент на HTTPS-страницах блокируются |
| Clear cookies on exit | Все cookies (включая контейнеры) удаляются при выходе |

### Пресеты приватности и первый запуск
Мастер первого запуска (только на чистом профиле — без settings.json на старте; существующие установки его не увидят) применяет глобальный пресет одной кнопкой: **Стандарт** (чистка URL, DNT/GPC, лёгкие списки блокировки), **Приватный** — по умолчанию (+ анти-фингерпринт, WebRTC-блок, HTTPS-only, блок 3rd-party cookies и mixed content, средний пресет блокировщика) или **Максимум** (+ блок автоплея/уведомлений/геолокации/буфера/WebGL, изоляция сайтов, максимальный пресет блокировщика). Затем предлагается установить мастер-пароль и открыть импорт данных из текущего браузера. Каждый переключатель пресета доступен по отдельности в таблице выше.

### Tor Hardening (CSP-переключатели)
Отключение JavaScript, блокировка WebGL, удалённых шрифтов, плагинов (`object`/`embed`), внешних iframe, запрет `<base>`.

### External services — внешние сервисы
Каждый endpoint виден и отключается: поисковые подсказки (Google/Yandex/DDG/Bing), переводчик (translate.googleapis.com), проверка утечек паролей (api.pwnedpasswords.com, k-anonymity — пароль не покидает устройство), диагностика соединения (check.torproject.org, ipapi.co, ipinfo.io, speed.cloudflare.com).

### SSL-сертификаты
Управление доверенными корнями: свои root-CA, включение/отключение системного набора (Mozilla root store). Используется и для Node-TLS (загрузки), и для Chromium-проверок.

## Proxy / Tor (`about:proxy`)

- Типы: HTTP, HTTPS, SOCKS4, SOCKS5, встроенный Tor.
- Tor-мосты: obfs4, snowflake, webtunnel; прогресс bootstrap, «Новая личность» (NEWNYM).
- Диагностика: exit-IP, гео, скорость — по кнопке (ходит через настроенный прокси).
- Watchdog: при падении прокси после нескольких неудачных проб переключает на прямое соединение и возвращает при восстановлении — следите за индикатором.

## Scripts — скрипты (`about:scripts`)

Пользовательские скрипты `.skit`: менеджер, импорт из файла, включение/отключение, журнал ошибок. Формат пакета и права — см. `docs/09-scripts.md` и `docs/12-developer-guide.md`.

## Customization — кастомизация (`about:themes`)

- Темы `.thmz` (ZIP: `theme.json` + `theme.css`), импорт/удаление, мгновенное превью.
- Редактор тем: `about:themeeditor` — палитры, акценты, экспорт.
- Dark Reader — профессиональный тёмный режим с настройками по сайтам.
- Custom CSS — свой CSS для интерфейса браузера.
- Панель инструментов: 27 кнопок, drag&drop, настройка через `about:customization`.
- Виджеты новой вкладки: часы, погода, календарь, цитаты — включаются по отдельности.

## Hotkeys / Vim (`about:hotkeys`)

Все горячие клавиши + Vim-режим (hjkl-навигация, `d`/`u` скролл, `/` поиск). Клавиши Vim переназначаются.

---

## Backup — бэкапы (`about:backup`)

- Экспорт `.spzi`: полный (с паролями; AES-256-GCM, пароль обязателен) или без секретов.
- Восстановление: выбор файла, предпросмотр содержимого, применение.
- Автобэкап при выходе (история/заметки; пароли — только в ручном полном бэкапе).

---

## Profiles — профили

Профили с отдельными данными (история, cookies, закладки) и опциональным паролем разблокировки. Переключение из панели профиля на тулбаре.

---

## Optimization — оптимизация

Засыпание вкладок (после N минут), eco-freeze анимаций, Data Saver (блокировка тяжёлых ресурсов), Battery Saver, прозрачность окна, ограничение процессов.

## Site Info (замочек в адресной строке)

- Состояние соединения: «Вы подключены к сайту по защищённому соединению» / предупреждение.
- SSL-сертификат: протокол/шифр, кому/кем выдан, срок действия — из реального соединения.
- **Удалить cookie и данные сайта** — полный сброс домена (cookies, localStorage, IndexedDB, service workers, кэши).
- **Подробнее о странице**: заголовок, адрес, тип, тип визуализации, кодировка, размер, ссылающийся URL, последнее изменение, мета-теги.
- Разрешения сайта: JavaScript, cookies, камера/микрофон, уведомления, геолокация (+ подмена координат), буфер и др.
