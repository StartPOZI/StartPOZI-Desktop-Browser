# Описание браузера: сильные и слабые стороны

> Документ отражает актуальное состояние кодовой базы (аудит + цикл исправлений). Версия: 1.0.0 beta, Electron 42, лицензия GPL-3.0.

## Описание

**StartPOZI Desktop Browser** — независимый десктопный браузер на базе Electron (Chromium), созданный с нуля и ориентированный на максимальную приватность и прозрачность. Проект распространяется по лицензии GNU GPL v3.0, телеметрии и скрытых трекеров нет, все настройки по умолчанию настроены на защиту от слежки.

Ключевые характеристики:

| Параметр | Значение |
|---|---|
| Движок | Chromium (Electron 42) |
| Табы | `<webview>`-элементы, по процессу на вкладку |
| Окна | Frameless + transparent, кастомный тайтлбар |
| Хранение данных | `userData` (settings.json + файлы профилей) |
| Платформы | Windows, Linux, macOS |
| Языки интерфейса | Русский, английский |
| Ядро приватности | Каталог [FilterHub](https://github.com/StartPOZI/FilterHub) + собственные слои защиты |

Функциональный охват (кратко):

- **Приватность**: блокировщик рекламы на каталоге FilterHub (44 списка, включаются по отдельности, 3 пресета защиты), автоотклонение cookie-баннеров, авто-удаление cookie при выходе, Tor-менеджер с мостами (obfs4/snowflake/webtunnel), прокси (HTTP/SOCKS4/SOCKS5), DoH, анти-фингерпринтинг, letterboxing, изоляция сайтов, очистка URL от сотен трекинг-параметров, управляемые внешние сервисы
- **Пароли**: менеджер с мастер-паролем (AES-256-GCM + scrypt), шифрование на диске через safeStorage (DPAPI/Keychain/libsecret), TOTP-коды 2FA, проверка утечек (HIBP k-anonymity), биометрия, импорт из Google Authenticator
- **Вкладки**: группы, закрепление, гибернация, eco-freeze, контейнеры, workspaces, split view, перенос между окнами
- **Продуктивность**: Quick Commands (~60 команд), Vim-режим, переназначаемые хоткеи, мульти-поиск, OCR (tesseract.js), офлайн TTS (espeak-ng), перевод, скриншоты, QR-сканер, элемент-заппер
- **Кастомизация**: темы .thmz, кастомный CSS per-site, настройка тулбара (27 кнопок, drag&drop), обои и виджеты на новой вкладке
- **Данные**: профили, бэкапы .spzi (AES-256-GCM), импорт из Chrome/Edge/Brave/Vivaldi/Firefox, диспетчер задач, проверка обновлений (GitHub Releases)

## Плюсы

### Приватность и безопасность

1. **Многослойный блокировщик рекламы** — каталог [FilterHub](https://github.com/StartPOZI/FilterHub) (44 списка из EasyList/EasyPrivacy, uBlock Origin, AdGuard, HaGezi, Phishing Army, Fanboy и др., ~3,4 млн правил) с индивидуальными переключателями каждого списка и тремя пресетами защиты (Light 7 / Medium 17 — по умолчанию / Maximum 44, по LEVELS.md апстрима) + ~110 хардкод-правил + ~50 доменов безусловной блокировки + пользовательские правила и сторонние списки. Косметическая фильтрация во всех фреймах с поддержкой extended-CSS (`:has()`, `:has-text()`).
2. **Умный автоотклонитель cookie-баннеров** — эвристический «кликер» с ~70 провайдер-специфичными селекторами (OneTrust, Cookiebot, Didomi, Sourcepoint, TrustArc…), поддержкой shadow DOM и обходом same-origin iframe. Предохранитель `ACCEPT_RE` гарантирует, что кнопка «Принять» никогда не будет нажата.
3. **Авто-удаление cookie при выходе** — опциональная очистка cookie (включая партиции контейнеров) при закрытии браузера; инкогнито-партиции стираются и так.
4. **Полноценный Tor-менеджер** — внешний `tor` с генерируемым torrc, мосты obfs4/snowflake/webtunnel, смена личности (NEWNYM), авто-детект, bootstrap-прогресс, Tor-hardening через CSP-тумблеры с уровнями standard/safer/safest. DNS через прокси для `.onion`.
5. **Глубокий анти-фингерпринтинг без противоречий** — шум в Canvas и AudioContext, подмена `hardwareConcurrency`/`deviceMemory`, блок WebRTC-утечек, letterboxing, spoof геолокации, поддельные камера/микрофон, noop `sendBeacon`. Спуф платформы соответствует реальной ОС (Win32/MacIntel/Linux x86_64) — маскировка под Chrome больше не создаёт рассогласования, само по себе являвшегося фингерпринтом.
5a. **Рабочий вход в Google** — на страницах логина (accounts.google.com, myaccount/passwords/pay/wallet, accounts.youtube.com, Apple/Microsoft login) браузер представляется **Firefox** через engine-level CDP-override (Google не запускает Chrome-аттестацию для Firefox-UA, а фингерпринт самого Chromium-билда Electron заблокирован независимо от маскировки — проверено сообществом, включая castlabs). Firefox-профиль зеркалирует реальный Firefox: UA-строка, **ноль** client-hints заголовков (sec-ch-ua*/x-client-data удаляются), `navigator.userAgentData` = undefined и `window.chrome` = undefined до первого скрипта страницы. На остальных страницах — обычная Chrome-маскировка. Все injected-глобалы non-enumerable, переопределения `alert/confirm/prompt/canvas/sendBeacon` замаскированы под `[native code]`, `getHighEntropyValues` фильтрует по запрошенным hints, plugins с настоящими прототипами (`instanceof PluginArray`), `platformVersion` согласован между JS/CDP/заголовками.
6. **Аккуратная архитектура preload** — `contextIsolation: true`, `nodeIntegration: false` везде; полный `electronAPI` только внутренним `file://`-страницам каталога приложения; **пер-страничная фильтрация прав**: пароли/vault/бэкапы доступны только Settings и Library, управление прокси/Tor и импорт настроек — только Settings (XSS в любой другой внутренней странице не даёт доступа к секретам); `will-attach-webview` принудительно фиксирует безопасные атрибуты каждого webview; `viewer-read-file` доступен только самому Viewer.html.
7. **Живые мосты страница↔браузер** — баннеры `alert/confirm/prompt`, hover-перевод и Super Drag работают через консольный транспорт (main world → `console-message` → main-процесс → `executeJavaScript`), не зависящий от сломанных в Electron 42 меж-мировых postMessage.
8. **Серьёзный менеджер паролей** — AES-256-GCM, ключ scrypt (N=16384, per-user salt), timing-safe verifier, TOTP, HIBP с кешем диапазонов, аудит паролей, биометрия (Touch ID / fprintd); без мастер-пароля пароли запечатываются safeStorage — plaintext на диске исключён.
9. **Приватность по умолчанию** — HTTPS-only, блок смешанного контента и сторонних cookie, обрезка Referer, fail-closed разрешения, DNT + Sec-GPC во всех запросах, отключённый hyperlink auditing (`<a ping>`), эфемерный журнал блокировок, санитизация имён загрузок, безопасный распаковщик архивов.
10. **Прозрачные внешние сервисы** — все сторонние endpoints собраны в одном месте и отключаются по отдельности (Settings → Security → External services): поисковые подсказки, переводчик, проверка утечек, диагностика соединения.
11. **Защита от слежки платформы** — отключение KWallet-интеграции, запрет autoplay без жеста, удаление диагностических логов при старте.

### Функциональность

12. **Инструменты «пауэр-юзера»** — Quick Commands (~60 команд + пользовательские с алиасами и цепочками), полноценный Vim-режим, мульти-поиск, поиск по всем вкладкам, split view, элемент-заппер (пикер в main world с isTrusted-фильтром, работает на Trusted Types-сайтах вроде YouTube).
13. **Богатое управление вкладками** — группы, гибернация с белым списком, eco-freeze, авто-усыпление при нехватке памяти, Session Guard, tear-off в отдельное окно, контейнеры на изолированных партициях, workspaces.
14. **Встроенные офлайн-инструменты** — OCR (tesseract.js), TTS (espeak-ng WASM в utilityProcess), перевод, QR-сканер, просмотрщик локальных файлов, эквалайзер, режим чтения, заметки на страницу.
15. **Импорт из других браузеров** — Chrome/Edge/Brave/Vivaldi/Firefox через чтение их SQLite (sql.js).
16. **Резервное копирование** — формат .spzi с шифрованием AES-256-GCM (случайная соль, тег целостности), автобэкап, ротация 10 копий, чтение старых форматов.
17. **Проверка обновлений** — GitHub Releases API через `net.fetch` (уважает Tor/прокси): авто-чек раз в 24 ч + кнопка в About; тихой установки нет — осознанный выбор приватного браузера.
18. **Новая вкладка как рабочий стол** — sandbox-виджеты (часы, календарь, погода с ручными координатами, цитаты, To-do), свои виджеты, обои, живые обои, плитки-ярлыки.
19. **Устойчивое и быстрое хранилище** — выделенный модуль storage.js: файл парсируется один раз (кэш в памяти — 220+ IPC-хендлеров больше не делают синхронное чтение с диска), атомарная запись (tmp + rename: сбой или потеря питания не портят файл), гонко-безопасный `update(fn)` для read-modify-write, bloat guard; прогресс загрузок пишется только в UI, а не на диск.

### Инженерные решения

20. **Опциональная производительность окна** — «Disable window transparency» (Settings → Optimization): непрозрачное окно без накладных расходов композитинга для слабых GPU (особенно Linux).
21. **Доступность** — пункты меню — настоящие `<button>`, вкладки с `role="tab"` и aria-метками, `role="tablist"`, глобальный `:focus-visible`, автоматическое зеркало `title → aria-label` для всего UI, включая динамические элементы.
22. **Продуманные мелочи** — белый список «авторизационных» доменов в блокировщике (OAuth/2FA не ломаются), fallback-движок при недоступности списков, инвалидация кэша движка по сигнатуре выбора списков.
23. **Офлайн-first** — иконки Font Awesome и QR-декодер вендорены, без CDN-зависимостей.
24. **Асинхронный main-процесс** — все системные вызовы (tor-детект, регистрация браузера в ОС) через `execFile` без блокировки UI.

## Честно о слабых местах

Проект молодой, и главная его слабость — инженерная, а не пользовательская: код пока представляет собой несколько очень больших файлов, поэтому новым разработчикам нужно время на погружение (модуляризация идёт: storage.js, lib/filter-checksum.js, lib/url-cleaner.js, lib/skit-manifest.js; чистые модули покрыты автотестами — `npm test`). Часть решений — осознанные компромиссы: движок блокировщика построен на архивированной библиотеке @cliqz/adblocker (пока заменять нечем), а для входа в Google используется CDP-override юзер-агента — это может конфликтовать с пользовательскими DevTools на конкретной вкладке. Списки фильтров проверяются по ABP-чексуммам: скачивание с несовпавшей контрольной суммой отбрасывается с откатом на кэш (см. lib/filter-checksum.js и тесты). Это MD5-чексумма без ключа — она защищает от порчи и обрыва при скачивании, но не от намеренной подмены с пересчётом чексуммы; от целенаправленной подмены защищает HTTPS-транспорт. Есть и мелкие шероховатости: языков интерфейса пока три (English, полный русский и частичный украинский с фолбэком на английский; новые языки добавляются файлом в locales/ без правок кода), экспорт паролей в CSV/JSON по определению нешифрованный, а изоляция вкладок через отдельные процессы делает браузер прожорливее одноконтейнерных конкурентов — этот недостаток мы смягчаем гибернацией и eco-freeze. В плане развития: дальнейшая модуляризация монолитов, расширение покрытия тестами и полные переводы.
